# Shared vocabulary

- **Run:** One bounded investigation of one industry and user objective.
- **Lane:** An independent, read-only evidence-search direction.
- **Evidence record:** One atomic claim paired with an opened source and verification status.
- **Frontier map:** The synthesis of established facts, contested claims, active approaches, and unresolved questions.
- **Opportunity:** A research gap scored on public benefit, decision value, neglectedness, computational tractability, readiness, time to impact, equity, and risk.
- **Hypothesis:** A preregistered, falsifiable claim with a comparator, primary metric, minimum effect, assumptions, and rejection rule.
- **Registered experiment:** Reviewed code exposed through a stable identifier; the local runner accepts no arbitrary code path.
- **Evidence barrier:** The point at which all independent lanes finish so a single writer can deduplicate and synthesize their records.
- **Single writer:** The only process allowed to mutate canonical run state at a stage.
- **Skeptic:** A fresh reviewer whose default is “not established” until sources or results support a claim.
- **Dry round:** A search round that adds no decision-relevant, verified evidence.
- **Reproducible:** A clean rerun from frozen inputs and seeds produces declared outputs within the stated tolerance; this does not imply external validity.
